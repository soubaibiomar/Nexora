\section{Présentation du Projet}
% ══════════════════════════════════════════════════════════════

Nexora est une plateforme d'intelligence organisationnelle propulsée par l'Intelligence Artificielle. Elle vise à cartographier les compétences, découvrir les experts internes, prédire les besoins en talents, et accélérer le partage des connaissances grâce à des analyses basées sur des graphes.

% ══════════════════════════════════════════════════════════════
\section{Contexte et Problématique}
% ══════════════════════════════════════════════════════════════

Les grandes organisations souffrent souvent de silos d'information et d'une mauvaise visibilité sur les compétences internes. Il est difficile de constituer des équipes optimales, d'identifier les déficits de compétences à venir, et de trouver le bon expert pour un problème donné. Nexora résout ce problème en centralisant les données RH, les projets, et les publications dans un graphe de connaissances dynamique.

% ══════════════════════════════════════════════════════════════
\section{Objectifs}
% ══════════════════════════════════════════════════════════════

\begin{itemize}[leftmargin=*]
    \item Cartographier visuellement les compétences et les relations au sein de l'organisation (Graphe 3D).
    \item Identifier les experts internes via un algorithme de ranking avancé (PageRank).
    \item Prédire les déficits de compétences futurs et détecter les compétences technologiques émergentes.
    \item Suggérer des collaborations inter-départementales pertinentes pour briser les silos.
    \item Traiter des données à grande échelle (Big Data) via des analyses par lot (Apache Spark) et du streaming (Kafka).
\end{itemize}

% ══════════════════════════════════════════════════════════════
\section{Périmètre Fonctionnel}
% ══════════════════════════════════════════════════════════════

\subsection{Sécurité et Accès}
\begin{itemize}[leftmargin=*]
    \item Authentification sécurisée par token JWT et hachage bcrypt.
    \item Page de connexion et d'inscription obligatoire pour accéder à la plateforme.
    \item Contrôle d'accès basé sur les rôles (RBAC) : Admin, Manager, User.
\end{itemize}

\subsection{Fonctionnalités Utilisateur (Standard)}
\begin{itemize}[leftmargin=*]
    \item Navigation dans l'explorateur de graphe interactif en 3D.
    \item Recherche intelligente d'experts par compétences, localisation ou département.
    \item Tableau de bord \textit{Skill Evolution} (Tendances, Prévisions, Collaborations).
    \item Recommandations personnalisées (parcours d'apprentissage, experts similaires).
    \item Interaction en langage naturel avec l'assistant IA (Veda).
    \item Espaces de travail d'équipe (Workspaces) avec chat en temps réel.
\end{itemize}

\subsection{Fonctionnalités Administrateur}
\begin{itemize}[leftmargin=*]
    \item Toutes les fonctionnalités utilisateur.
    \item Gestion des utilisateurs : modification des rôles et supervision globale.
    \item Accès aux métriques Big Data : statut du pipeline d'ingestion (simulateur Kafka) et rapports Spark.
\end{itemize}

% ══════════════════════════════════════════════════════════════
\section{Architecture et Choix Techniques}
% ══════════════════════════════════════════════════════════════

\begin{itemize}[leftmargin=*]
    \item \textbf{Frontend :} React 18, TypeScript, Material UI (MUI), Vite, react-force-graph-3d.
    \item \textbf{Backend :} FastAPI (Python 3.11), Uvicorn, Pydantic.
    \item \textbf{Base de données :} Neo4j (Graph Database) version 5 avec le plugin APOC.
    \item \textbf{Intelligence Artificielle :} Scikit-learn (TF-IDF, Filtrage Collaboratif, PageRank), Modèles LLM (OpenAI API).
    \item \textbf{Big Data :} PySpark (Analyses en lot), Simulateur de pipeline de type Apache Kafka.
    \item \textbf{Déploiement :} Docker, Docker Compose, serveur proxy Nginx.
\end{itemize}
